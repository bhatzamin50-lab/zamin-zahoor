# Smart Hotel Management & Analytics System

A first-semester student project built with Core Python, NumPy, Pandas, Matplotlib, Seaborn, Flask, HTML and CSS.
All records live in CSV files inside `data/` (no database). The data is **sample hotel data, not real customers**.

## Run
1. Install Python 3.9+.
2. `pip install -r requirements.txt`
3. `python app.py`
4. Open http://127.0.0.1:5000 and click **Get Started**.

## How it works
- `app.py` – Flask routes, CSV load/save (Pandas), validation, NumPy calculations, chart creation.
- `templates/` – HTML pages (`base.html` holds the shared sidebar layout).
- `static/css/style.css` – navy and gold theme, responsive layout, animations.
- `static/charts/` – chart images generated by Matplotlib and Seaborn.

## Rules used
- Room status Available/Booked is updated automatically from today's bookings; Maintenance is set by hand.
- A room cannot be booked for dates that overlap another non-cancelled booking.
- Total booking cost = price per night x nights.
- Revenue = total of bills marked Paid.
- Team portfolio links on the landing page are placeholders (`PORTFOLIO_LINKS` in `app.py`).
