About our project

This semester project helps hotel staff keep track of rooms, guests, bookings, and payments, and then turns those records into charts that show how the hotel is performing.

Objectives

Replace paper registers with one simple system, avoid double bookings, calculate bills automatically, and show business results as charts.

Python and Flask

Core Python holds the logic. Flask connects each web page to the code with routes.

Pandas and CSV

Records are stored in CSV files. Pandas reads, filters, updates, and summarises them.

NumPy

NumPy arrays do the number work, such as totals, averages, and booking cost.

Matplotlib and Seaborn

These libraries draw the charts that appear on the Analytics page.
